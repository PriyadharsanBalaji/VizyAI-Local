# AI Visualization & Insights Tool - Ollama Local Edition

Fully local AI-powered data visualization and insights using Ollama vision models. **No API costs, no rate limits, complete privacy!**

## Features

- 📊 **Automated Visualization**: 30+ graph types (PCA, t-SNE, SOM, correlations, distributions)
- 🤖 **Local AI Analysis**: Multi-stage LangGraph workflow with vision models
- 💰 **Zero Cost**: Runs completely locally using Ollama
- 🔒 **Private**: Your data never leaves your machine
- ⚡ **No Rate Limits**: Process as much data as you want

## Hardware Requirements

- **RAM**: 16GB minimum (recommended for llama3.2-vision:11b)
- **Storage**: 10GB for model + space for your data
- **GPU**: Optional but recommended for faster inference
